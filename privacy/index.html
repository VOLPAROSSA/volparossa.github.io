About this website

A quieter visit.

A static website, without site-added tracking.

What this site does

This website serves public pages, images and fonts. It adds no analytics, advertising, third-party embeds, cookies or browser storage. All fonts, scripts and images are hosted with the site. The small optional script only improves menu behaviour.

Hosting still involves requests

GitHub Pages hosts this website. Requests may be recorded by the hosting provider, including information such as IP addresses and request details, under its own policies. An absence of site-added analytics does not mean an absence of hosting logs. Read the GitHub privacy statement .

When you follow a link

Links to GitHub, application repositories and upstream projects take you to independent services with their own privacy policies. They are ordinary links, not embedded connections.

Project privacy is a separate subject

The Core privacy documentation explains the developing network's boundaries. This website makes no guarantee about the privacy or readiness of unfinished applications.
