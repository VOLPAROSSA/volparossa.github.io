Start a useful conversation.

Use central Discussions on GitHub ↗ for general questions and ideas across projects. Report actionable bugs in the repository that owns them. Issue labels help identify scope; they do not promise mentoring or immediate review.

Before changing code, read the contribution guide ↗ and code of conduct ↗. Keep private data out of reports and use the documented disposable environment for network tests.

Support the shared work.

Independent verification, accessible documentation and relevant research all help. The supporting guide on GitHub ↗ explains current needs and verified contact routes. It currently publishes no live sponsorship or payment offer. No donation is required to contribute.
