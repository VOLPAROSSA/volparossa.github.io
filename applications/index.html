One shared foundation

Many ways to make it useful.

Familiar open-source tools and new research, connected by the ambition to build together.

Every application is in development or research. Explore the repositories for current evidence, setup instructions and open work. Application websites will join this library as they become available.

  • Code

    Built on OpenCode

    Building on OpenCode to connect coding workflows with VOLPAROSSA's cooperative compute foundation.

    A bounded local model can read, edit and test a public fixture. Native editor operation and confidential peer coding remain unfinished.

    Integration in developmentExplore Code · GitHub

  • Image

    Built on Immich

    Building on Immich to connect photo libraries with VOLPAROSSA's shared storage foundation.

    Encrypted snapshot recovery has a scoped peer-storage proof. Live library operation, device sync and server-independent mobile use remain unfinished.

    Integration in developmentExplore Image · GitHub

  • Cloud

    Built on OpenCloud

    Building on OpenCloud to connect files and collaboration with VOLPAROSSA's shared infrastructure.

    The original Files interface has scoped upload and recovery proofs. Accounts, sharing, writable sync and recovery on another device remain unfinished.

    Integration in developmentExplore Cloud →Source on GitHub

  • Browser

    Built on Firefox

    Protected connectivity, eligible content caching and cooperative AI for a familiar browser.

    Integration in developmentExplore Browser · GitHub

  • Chat

    Built on Signal

    Messaging and calls with private backups, preserving Signal Protocol semantics.

    Integration in developmentExplore Chat · GitHub

  • Mail

    Built on Thunderbird and Stalwart

    Existing email accounts, cooperative delivery and optional self-hosting.

    Integration in developmentExplore Mail · GitHub

  • Map

    Built on Organic Maps

    Offline maps and navigation, with shared map data and positioning research.

    Integration in developmentExplore Map · GitHub

  • Weather

    Built on Drizz.li and Overmorrow

    Direct public weather-model data, beginning with ECMWF, shared through Core.

    Integration in developmentExplore Weather · GitHub

  • Studio

    Built on Silex

    Visual website creation, portable export and a path toward shared hosting.

    Integration in developmentExplore Studio · GitHub

  • Bank

    Original research

    Participant-owned portfolio and transaction research. No live banking or payment service.

    Research and simulationExplore Bank · GitHub

  • Citizen

    Original research

    Proposals and referendum procedures using fictional identities. Real-person voting remains open.

    Research and simulationExplore Citizen · GitHub
